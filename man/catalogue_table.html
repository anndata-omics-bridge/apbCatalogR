The catalogue sets as one long table

Description

One row per entry and rule it applies to, as apb-catalog table prints it.

Usage

catalogue_table(catalogue = NULL)

Arguments

catalogue One set’s name; NULL lists every set of the bundle.

Value

A data frame with columns set, source (the vendor, producer:<name> or annotation:<convention>), version_pattern, rule (* for an entry of every rule), level, location, table, name (role:<role> or prefix:<prefix> for a field found by role or column-name prefix), one qualifier.<name> column per qualifier, requirement and entry_id.

Examples

library("apbCatalogR")

head(catalogue_table("confidence"))
