What one result’s fields mean to one consumer

Description

Answers on a result read with read_parsed_levels() and hands the data back directly. A lookup asks by one of the set’s keys, such as “q_value” or Sage’s “quantification_q_value”. Ambiguous or unreviewed answers signal UnresolvedField.

Value

The class generator; DataCatalog$new() returns a DataCatalog.

Public fields

levels
One Level per level of the result, with anndataR’s slots looked up by key.

Active bindings

description
What this catalogue set holds and who uses it.

DataCatalog$new()

Bind catalogue sets to the levels of one result; apb, APB’s own fields, is always in.

Usage 
DataCatalog\$new(result, ..., enforce = NULL)
Arguments
result
A ParsedLevels object.
…
The catalogue sets, such as “abundance” and “confidence”; see catalogues().
enforce
NULL, “MUST” or “SHOULD”: signal MissingRequiredField when a field a set requires at that strength is missing.

DataCatalog$keys()

The keys the level offers at one location, given further qualifiers, from every set that declares those qualifiers.

Usage 
DataCatalog\$keys(level, location, ...)
Arguments
level
The quantification level.
location
“layers”, “var” or “obs”.
…
Further qualifiers by name, besides those the key fixes.
Returns

A character vector.

DataCatalog$layer()

The layer with this meaning.

Usage 
DataCatalog\$layer(level, key, ...)
Arguments
level
The quantification level.
key
The key, such as “pep”; see catalogue_table().
…
Further qualifiers by name, besides those the key fixes.
Returns

An observations-by-features matrix, or NULL when the result has no such layer.

DataCatalog$var()

The per-feature column with this meaning, from var or a varm table.

Usage 
DataCatalog\$var(level, key, ...)
Arguments
level
The quantification level.
key
The key.
…
Further qualifiers by name, besides those the key fixes.
Returns

A vector, or NULL.

DataCatalog$obs()

The per-sample column with this meaning.

Usage 
DataCatalog\$obs(level, key, ...)
Arguments
level
The quantification level.
key
The key.
…
Further qualifiers by name, besides those the key fixes.
Returns

A vector, or NULL.

DataCatalog$fields()

Every catalogued field of the result in every composed set, one row per field, as catalogue_table() shows them.

Usage 
DataCatalog\$fields()
Returns

A data frame with present and, for a field apb2 left out because it held one value, that constant.

DataCatalog$print()

Print the set and the levels.

Usage 
DataCatalog\$print(...)
Arguments
…
Ignored.

DataCatalog$clone()

The objects of this class are cloneable with this method.

Usage 
DataCatalog\$clone(deep = FALSE)
Arguments
deep
Whether to make a deep clone.

Examples

library("apbCatalogR")

results <- tempfile()
archive <- system.file("extdata", "test-bundle", "results.tar.gz", package = "apbCatalogR")
utils::untar(archive, exdir = results)
result <- read_parsed_levels(file.path(results, "maxquant_wide-peptidoform_ion.parquet"))
catalog <- DataCatalog$new(result, "confidence")
dim(catalog$layer("peptidoform_ion", "pep"))
